Featured Projects

AbyFlow — Multi-Tenant SaaS Billing & AI Platform Live
Live ↗ Code ↗

A multi-tenant billing backend where each workspace manages its own customers, invoices and role-based access (platform and workspace roles), with tenant isolation enforced in queries and vector retrieval. Stripe webhooks are saved safely before replying 200 OK, using PostgreSQL row locking (SKIP LOCKED) and lease tokens so background Celery workers never overwrite each other, with automatic retries and a manual replay tool for failed events. A Gemini-powered billing assistant uses embeddings and pgvector, tracks token usage and cost per request, and is read-only: it can view billing data but never change or calculate it. Covered by 285 automated tests, including PostgreSQL integration tests for locking and concurrency. Deployed to AWS EC2 behind an Nginx reverse proxy with HTTPS — running alongside AbyVest on a single t3.small instance, with isolated internal ports for the app, database, and cache layers.

Python Flask Celery Redis PostgreSQL pgvector Stripe Gemini API Docker Nginx AWS EC2
AbyVest — Real-Time Portfolio Tracker Live
Live ↗ Code ↗

A real-time stock portfolio tracker powered by Finnhub and Gemini APIs, with tiered Redis caching (60s TTL for live quotes, 24h for company profiles) to cut external API calls and avoid rate limits. External API logic is separated from route handlers into a service layer, and a context-injection system formats each user's PostgreSQL portfolio data into structured prompts for AI analysis. Deployed to the same AWS EC2 host as AbyFlow via Nginx path-based routing, with PostgreSQL and Redis isolated on internal-only ports.

Python Flask Redis PostgreSQL Finnhub API Gemini API Nginx AWS EC2
